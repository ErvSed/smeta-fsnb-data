# База ФСНБ-2022 для приложения smeta-fsnb

Готовая база SQLite из **открытых данных ФГИС ЦС** (набор `7707082071-fsnb`),
уровень цен 01.01.2022: 56 192 нормы, 545 655 ресурсных строк,
45 437 материалов, 1 732 машины. Размер 216 МБ (в архиве 24 МБ).

Файл `smeta.sqlite.gz` — в разделе Releases. Приложение `ErvSed/smeta-fsnb`
скачивает архив и распаковывает его в `data/smeta.sqlite`.
